My first program is about how to detect the campus network data usage

My second program is an SDN (Software-Defined Networking) control system that uses Large Language Models (LLMs) to translate natural language commands (like "block host A") into OpenFlow rules for network switches. Delivered as a single, easy-to-run file, it features a web dashboard for network topology visualization, connectivity testing, and rule management, and can run in either a lightweight Windows simulation mode or a real Linux/Mininet environment.
